# Overview 

Welcome to **SkyLogs**, a modern alerting and incident management platform designed to help your team detect, respond, and automate incidents faster.

This guide will get you **up and running quickly**, so you can see SkyLogs in action and understand its core capabilities.

---

### 1️⃣ Quick Start (5 Minutes)

Get SkyLogs working in **just five minutes**.
This path focuses on the **fastest way to receive your first alert notification**, without requiring external monitoring systems.

**You will:**

* Install SkyLogs quickly
* Configure a contact point (Slack, Email, Webhook)
* Send a test alert using the API
* Receive your first notification


[Go to Quick Start →](./quickstart)

---

### 2️⃣ Full Stack Demo (15–20 Minutes)

Experience SkyLogs with **real monitoring systems**.
This path demonstrates SkyLogs’ full power with multiple datasources, realistic alerts, grouping, routing, and incident automation.

**You will see SkyLogs in action with:**

* Prometheus metrics
* Kubernetes events
* Blackbox monitoring
* Grafana alerts
* Optional database monitoring (PMM)
* Automatic alert grouping and incident creation

> Ideal for DevOps teams, SREs, and managers who want to explore SkyLogs in a real production-like environment.

[Go to Full Stack Demo →](./full-stack-demo)

---

## Why We Split Getting Started

* **Quick Start:** fast, zero dependencies, reliable — get a taste in 5 minutes.
* **Full Stack Demo:** realistic, interactive, demonstrates advanced features — takes 15–20 minutes.

This separation ensures that everyone can start with success **immediately**, and explore **full capabilities** when ready.

After completing either path, you can continue to:
